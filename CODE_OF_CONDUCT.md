# Code of Conduct

This project has adopted the Contributor Covenant, version 2.1, as its code of
conduct. The full text is published at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

All contributors and participants in project spaces (issues, pull requests,
discussions and any other channel) are expected to follow it.

## Enforcement

Instances of unacceptable behaviour can be reported privately to the project
maintainer. Use GitHub private vulnerability reporting for the repository
(<https://github.com/babbguy/Modus/security/advisories/new>) or contact the
maintainer through their GitHub profile, noting that the report concerns the
Code of Conduct. All reports will be reviewed and handled fairly,
and the reporter's privacy will be respected.

The maintainer follows the enforcement guidelines described in the Contributor
Covenant when deciding on any consequences.
