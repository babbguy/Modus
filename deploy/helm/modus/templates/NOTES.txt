   kubectl logs -n {{ .Release.Namespace }} deploy/{{ include "modus.fullname" . }}-orchestrator -c migrate

2. Create a team and issue its registration token. The master key (from the
   {{ if .Values.secrets.create }}{{ include "modus.secretName" . }}{{ else }}{{ .Values.auth.existingSecret }}{{ end }} secret) authenticates admin calls in either auth mode,
   sent as the X-Modus-APIKey header. Treat it like a root password:
   curl -X POST http://ORCHESTRATOR_URL/api/v1/teams      -H "X-Modus-APIKey: YOUR_MASTER_KEY" -H "Content-Type: application/json"      -d '{"slug": "my-team", "name": "My Team"}'
   curl -X POST http://ORCHESTRATOR_URL/api/v1/teams/TEAM_ID/registration-token      -H "X-Modus-APIKey: YOUR_MASTER_KEY"
{{- if eq .Values.orchestrator.config.authMode "jwt" }}
   The dashboard sign-in accepts either that master key or a JWT signed with the
   secret in {{ if .Values.secrets.create }}{{ include "modus.secretName" . }}{{ else }}{{ .Values.auth.jwt.existingSecret }}{{ end }} (MODUS_JWT_SECRET).
{{- end }}

3. Instrument an application with the Python SDK, then set MODUS_URL and
   MODUS_TEAM_TOKEN in its environment:

   and make `import modus` the first import of the application.
